# XLSX Workflow

## Use Cases
- Data exports
- Operational reports
- Template-based imports

## Steps
1. Define schema and column types.
2. Generate workbook with stable sheet names.
3. Apply formatting for readability.
4. Validate formulas, dates, and encodings.

## Output Checks
- Headers are correct.
- Numeric/date values are typed, not plain text.
- Openable in Excel and common alternatives.
