# Skill Creator Workflow

## Goal
Create reusable skills that improve task quality and speed.

## Steps
1. Define narrow problem scope.
2. Write trigger conditions and boundaries.
3. Add step-by-step execution guidance.
4. Include validation and fallback behavior.
5. Provide minimal examples.

## Quality Gate
- Instructions are unambiguous.
- Scope is limited and testable.
- Outputs are consistent across runs.
