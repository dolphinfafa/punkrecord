# PDF Workflow

## Use Cases
- Reports
- Proposals
- Printable summaries

## Process
1. Build from structured source content.
2. Validate typography, margins, and pagination.
3. Ensure links, tables, and images render correctly.
4. Run final readability check at 100% zoom.

## Deliverables
- Final PDF
- Source file or generation script
