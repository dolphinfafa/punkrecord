# Canvas Design Workflow

## Objective
Produce a clear, printable or digital canvas for strategy or ideation sessions.

## Steps
1. Define audience, context, and expected decisions.
2. Choose section layout (left-to-right or top-down flow).
3. Add prompts that force concrete responses.
4. Validate with one dry run using realistic content.

## Quality Bar
- Fast to scan in under 30 seconds.
- Sections have clear order and intent.
- Works on desktop and print.
