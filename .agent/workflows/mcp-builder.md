# MCP Builder Workflow

## Objective
Design MCP integrations that are reliable, secure, and easy to operate.

## Steps
1. Define capability and trust boundary.
2. Specify request/response contracts.
3. Implement error handling and retries.
4. Document setup and example calls.

## Validation
- Handles malformed input safely.
- Returns deterministic outputs where possible.
- Includes operational notes and limits.
