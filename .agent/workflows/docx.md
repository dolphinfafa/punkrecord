# DOCX Workflow

## Requirements
- Clean heading hierarchy
- Stable page layout and margins
- Export-safe tables and images

## Process
1. Build from template or style baseline.
2. Apply heading and paragraph styles only.
3. Insert media with captions and source notes.
4. Final pass for numbering and table consistency.

## Output
- DOCX file with standard styles
- Optional PDF export for review
