# Frontend Design Workflow

## Principles
- Prioritize clarity of information and action.
- Use a consistent design language.
- Keep interaction costs low.

## Steps
1. Define user tasks and page hierarchy.
2. Draft layout and content density.
3. Set typography, color tokens, and spacing scale.
4. Add meaningful motion and responsive behavior.
5. Validate accessibility and edge states.

## Done Criteria
- Desktop and mobile both render correctly.
- Empty/loading/error states are handled.
- Visual style is intentional, not generic.
