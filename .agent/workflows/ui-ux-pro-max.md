# UI/UX Pro Max Workflow

## Focus
Move from problem framing to validated interface decisions.

## Steps
1. Clarify user jobs and success metrics.
2. Map primary flows and failure paths.
3. Design wireframes, then high-fidelity UI.
4. Run quick usability checks.
5. Finalize specs for implementation.

## Acceptance
- Major user flows are complete.
- Error and empty states are designed.
- Handoff specs are implementation-ready.
