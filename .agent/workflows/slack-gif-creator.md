# Slack GIF Creator Workflow

## Objective
Produce lightweight GIFs optimized for chat delivery.

## Steps
1. Define message intent and tone.
2. Create a short storyboard (2-6 beats).
3. Render with readable text and safe contrast.
4. Optimize size for fast loading.

## Output Constraints
- Loop is smooth.
- Text stays legible on light/dark chat backgrounds.
- File size is practical for Slack sharing.
