# PPTX Workflow

## Narrative Arc
1. Problem
2. Evidence
3. Options
4. Recommendation
5. Next steps

## Slide Rules
- One core message per slide.
- Use data labels and source notes.
- Keep visual hierarchy strong and simple.

## Final Checks
- Speaker flow is coherent.
- Fonts and media are embedded or portable.
