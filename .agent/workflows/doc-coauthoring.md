# Document Co-authoring Workflow

## Collaboration Model
- One owner maintains structure and decisions.
- Contributors focus on assigned sections.
- Reviewers validate facts, logic, and language.

## Process
1. Lock outline before drafting.
2. Draft by section with explicit assumptions.
3. Run technical and language review.
4. Merge comments and publish changelog.

## Rules
- Avoid duplicated sections.
- Resolve conflicting terminology early.
- Keep references and dates explicit.
