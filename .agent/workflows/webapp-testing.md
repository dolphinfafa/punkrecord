# Web App Testing Workflow

## Test Strategy
- Smoke checks for critical flows
- Regression checks for changed areas
- Basic accessibility and responsiveness checks

## Execution
1. Identify high-risk paths.
2. Run targeted tests first.
3. Capture failures with clear repro steps.
4. Re-run after fixes.

## Report Format
- Findings ordered by severity
- Steps to reproduce
- Expected vs actual
- Affected files/routes
