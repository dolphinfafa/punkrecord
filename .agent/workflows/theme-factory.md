# Theme Factory Workflow

## Deliverables
- Color tokens
- Typography scale
- Spacing/radius/shadow tokens
- Component mapping notes

## Process
1. Pick visual direction and constraints.
2. Define base tokens.
3. Apply tokens to key components.
4. Validate contrast and interaction states.

## Rule
Tokenize decisions first; avoid hard-coded one-off styles.
