# 2026-06-08 Milestone

## MCP 服务 + 前端 MCP 集成页

### 1. 背景

把 PunkRecord 从「Claude Code Skill（REST 文档）」升级为一个**托管式 MCP 服务**（对标 tikhub.io/mcp）：AI 客户端（Claude Desktop/Code、Cursor、Cherry Studio 等）用 PunkRecord 密钥直接连接远程 MCP 端点调用工具。同时左侧导航新增「MCP」页面，提供 API 密钥管理、集成介绍、各客户端配置片段与工具文档。全部在 `dev` 分支，未动 main。

### 2. 后端 MCP 服务

- **`backend/app/api/mcp_server.py`**（新增）：官方 `mcp` SDK（FastMCP，Streamable HTTP），`stateless_http=True, streamable_http_path="/"`。19 个精选工具（读 13 + 写 6）。
- **认证 + 实现**：工具从请求头取 `Authorization: Bearer pat_xxx`（复用 Agent Token），用 `httpx` 携带该 token **转发本机 REST**（`INTERNAL_API_BASE_URL`）。零逻辑重复，权限/通知/项目联动与页面完全一致。
- **`main.py`**：改用 `lifespan`，`async with mcp.session_manager.run()` 启动会话管理器，`app.mount("/api/v1/mcp", mcp.streamable_http_app())`；新增 `GET /api/v1/mcp-info`（端点 URL + 工具列表）。复用 nginx `/api/` 代理，生产无需改 nginx。
- **`config.py`**：新增 `INTERNAL_API_BASE_URL`（dev 15085 / prod 9086）、`MCP_PUBLIC_URL`。

工具集：
- 读：get_me、list_my_todos、get_todo、list_todo_images、list_my_leaves、list_projects、get_project、list_project_todos、list_contracts、list_counterparties、list_transactions、search_kb、list_meetings。
- 写：create_todo（支持 project_name/project_id + dev_type + tags）、start_todo、submit_todo、block_todo、dismiss_todo、create_leave。

### 3. 依赖升级（关键）

官方 mcp SDK 需 **Python 3.10+**，且要求 `pydantic>=2.11`，连带 fastapi/starlette/uvicorn 升级。在 dev 实际运行环境（conda env `punkrecord`，Python 3.10）安装并验证出一套协调集，`requirements.txt` 已 pin：
- fastapi 0.135.1 / starlette 0.52.1 / uvicorn 0.41.0 / pydantic 2.12.5 / pydantic-settings 2.13.1 / sqlmodel 0.0.37 / httpx 0.28.1 / **mcp 1.27.2**。
- 升级后对现有 11 个路由全部冒烟通过（200，序列化正常）。

> 运行环境澄清：dev 后端由 **PM2** 托管（`punkrecord-backend`，env `punkrecord`，`uvicorn --reload`），不是 `dev.sh`（其 `PYTHON` 指向旧的 `punk` env）。排障时用 `pm2 restart punkrecord-backend`。

### 4. 前端 MCP 页面

- **`pages/mcp/McpPage.jsx` + `McpPage.css`**（新增）：介绍 + API 密钥管理（从工作台迁来，复用 `agentTokenApi`，生成/列表/删除/复制含 HTTP fallback）+ 端点 URL + 客户端配置 Tabs（Streamable HTTP：Cursor/Cherry Studio 的 JSON、Claude Code 命令行；Stdio：Claude Desktop 的 `npx mcp-remote` JSON）+ 工具列表（取自 `/mcp-info`）+ 快速开始。
- **`api/mcp.js`**（新增）：`getInfo()` → `GET /mcp-info`。
- **`Sidebar.jsx`**：新增 MCP 导航项（`/mcp`，Plug 图标，所有登录用户可见）。
- **`App.jsx`**：新增 `/mcp` 路由。
- **`DashboardPage.jsx`**：移除「Agent 密钥」区及相关 state/imports（迁至 MCP 页，单一入口）。

### 6. 部署注意（上生产时）

1. 生产服务器 Python 从 3.9 升级到 **3.10+**，按新 `requirements.txt` 安装（含 mcp 1.27.2）。
2. 设置 prod env：`INTERNAL_API_BASE_URL=http://127.0.0.1:9086/api/v1`、`MCP_PUBLIC_URL=https://punkrecord.yios.cn/api/v1/mcp`。
3. `pm2 restart punkrecord-api`。现有 nginx `/api/` 代理已覆盖 `/api/v1/mcp`，无需改 nginx。
4. 公开端点：`https://punkrecord.yios.cn/api/v1/mcp`。
