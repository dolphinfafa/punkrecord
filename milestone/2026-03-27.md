# 2026-03-27 Milestone

## 生产环境 Bug 修复 + 功能增强 + 模版修复

### 1. 背景

继 03-26 大批量修复后，QA 继续在生产环境测试，发现多个 500 错误、模版导入失败、验收报告内容缺失等问题。同时完善了任务创建流程中的分配人限制和审核人传递逻辑。

### 2. 生产 500 根因修复

**根因**：`todo_item.our_entity_id` 和 `leave_request.our_entity_id` 有外键约束指向 `our_entity` 表，但项目的 `our_entity_id` 实际存储的是 `counterparty` 表的 ID，创建 todo 时传入该 ID 违反外键约束。

**修复**：
- 开发库和生产库均 `ALTER TABLE DROP FOREIGN KEY`
- 后端模型 `TodoItem.our_entity_id` 和 `LeaveRequest.our_entity_id` 移除 `foreign_key` 定义
- 影响：功能清单保存、同步功能清单、新建开发任务、删除项目等操作恢复正常

### 3. 功能清单模版导入修复

**问题**：后端生成的模版第 1 行是合并标题"功能清单模板"，`XLSX.utils.sheet_to_json` 默认用第 1 行做表头，解析失败。

**修复**：前端导入时自动尝试行 1-3 作为表头，匹配 >=3 个已知列名才采用，彻底解决不同模版格式的兼容问题。

### 4. 同步功能清单增加确认弹窗

点击"同步功能清单任务"按钮后，弹出确认框提示"注意：如果同步了功能清单，现有的任务全部都会被清空。是否执行？"，防止误操作。

### 5. 任务创建分配人限制

- **项目详情→项目任务→新建任务**：所属项目自动锁定为当前项目，分配人只能选本项目成员
- **待办事项→新建任务**：选择关联项目后，动态加载项目成员，分配人下拉框只显示项目成员并标注"仅项目成员"
- 修复 `fixedProjectId` 时项目名称不显示的问题

### 6. 验收报告模版修复

| 问题 | 修复 |
|------|------|
| 项目信息缺甲乙方 | 增加"甲方（客户方）"和"乙方（我方）"两行 |
| 业务描述编号重复 | 去掉 `List Number` 样式，只保留手动编号 |
| 缺签字/盖章 | 验收日期上方增加"签字/盖章：________________" |

### 7. 文件下载路径修复

**问题**：`project.js` 和 `todo.js` 中验收报告、项目附件、任务图片的下载接口使用原生 `axios`，路径缺少 `/punkrecord` 前缀，生产环境 Nginx 下 404 导致下载为空。

**修复**：三处路径全部补上 `/punkrecord` 前缀。

### 8. 验收报告乙方名称为空

**问题**：`our_entity_id` 存的是 counterparty ID，代码用 `session.get(OurEntity, ...)` 查不到。

**修复**：验收报告和报价单导出中，先查 `OurEntity`，失败后 fallback 查 `Counterparty`。

### 9. 开发进度新建任务审核人

**问题**：开发进度页面新建任务时 `link` 中没传 `reviewer_user_id`，待办事项中审核人显示为创建人而非项目经理。

**修复**：`link` 中增加 `reviewer_user_id: project.pm_user_id`。
