# 2026-02-25 项目进度记录

## 今日工作总结

今天聚焦“项目管理 - 阶段与附件”能力，完成了附件方案重构、页面可用性优化与线上错误修复。

## 1. 附件能力重构（阶段级 -> 项目级）

### 1.1 交互改造
- 取消“每个阶段单独上传附件”的交互。
- 在项目详情页“阶段”模块右侧新增“附件”入口按钮。
- 点击后打开项目附件管理弹窗，统一管理本项目相关附件（如合同、原型确认单等）。

### 1.2 前端能力
- 新增 `ProjectAttachmentsModal`，支持：
  - 上传附件（单文件最大 20MB）
  - 查看附件列表
  - 下载附件
  - 删除附件
- 阶段表格移除“附件”列，界面更简洁。

### 1.3 后端接口
- 新增项目级附件接口：
  - `GET /api/v1/project/projects/{project_id}/attachments`
  - `POST /api/v1/project/projects/{project_id}/attachments`
  - `GET /api/v1/project/projects/{project_id}/attachments/{attachment_id}/download`
  - `DELETE /api/v1/project/projects/{project_id}/attachments/{attachment_id}`
- `Project` 模型新增 `attachments(JSON)` 字段用于存储附件元数据。

## 2. 稳定性修复（500 问题）

- 修复项目阶段接口中 `attachments=None` 导致的 Pydantic 校验失败（500）。
- 兼容措施：
  - 接口返回前兜底把空附件归一为 `[]`。
  - SQLite 启动时自动补齐 `attachments` 列并修复历史空值数据。

## 3. 阶段区域 UI 优化

- 阶段表格改为可横向滚动并设置列最小宽度，缓解拥挤。
- 操作区支持更合理换行，提升可读性与可操作性。

## 4. 文档与验证

## 5. 工作台请假与审批规则落地（追加）

### 5.1 请假业务规则
- L0 级别员工无需请假（禁止提交请假申请）。
- L0 以下员工提交请假，由其直属主管在“待我审批”列表中审批。
- 请假类型与额度：
  - 年假 5 天
  - 产假 15 天
  - 婚假 3 天
  - 事假 3 天
  - 病假 3 天
- 员工可在工作台查看自己的剩余额度。

### 5.2 审批与余额扣减
- 主管审批通过后：
  - 请假状态变为 `approved`
  - 自动扣减对应假期余额
- 主管驳回后：
  - 请假状态变为 `rejected`
- 取消“请假自动创建待办事项”方案，审批仅在请假申请模块内处理。

### 5.3 假期重置策略调整
- 取消“每年自动重置”。
- 改为 L0 在员工管理中手动触发全员重置。
- 新增接口：`POST /api/v1/iam/users/reset-leave-balances`（一键重置所有员工额度为默认值）。

### 5.4 员工管理体验优化
- 修复编辑员工弹窗黑底可读性问题：
  - 弹窗与表单改为高对比浅色风格，输入框与文字可见性显著提升。
- 将“重置假期余额”入口从“编辑员工弹窗”迁移到员工管理主页面统一入口，避免逐个员工操作。
