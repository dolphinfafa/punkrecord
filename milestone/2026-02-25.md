# 2026-02-25 项目进度记录

## 今日工作总结

今天聚焦“项目管理 - 阶段与附件”能力，完成了附件方案重构、页面可用性优化与线上错误修复。

## 1. 附件能力重构（阶段级 -> 项目级）

### 1.1 交互改造
- 取消“每个阶段单独上传附件”的交互。
- 在项目详情页“阶段”模块右侧新增“附件”入口按钮。
- 点击后打开项目附件管理弹窗，统一管理本项目相关附件（如合同、原型确认单等）。

### 1.2 前端能力
- 新增 `ProjectAttachmentsModal`，支持：
  - 上传附件（单文件最大 20MB）
  - 查看附件列表
  - 下载附件
  - 删除附件
- 阶段表格移除“附件”列，界面更简洁。

### 1.3 后端接口
- 新增项目级附件接口：
  - `GET /api/v1/project/projects/{project_id}/attachments`
  - `POST /api/v1/project/projects/{project_id}/attachments`
  - `GET /api/v1/project/projects/{project_id}/attachments/{attachment_id}/download`
  - `DELETE /api/v1/project/projects/{project_id}/attachments/{attachment_id}`
- `Project` 模型新增 `attachments(JSON)` 字段用于存储附件元数据。

## 2. 稳定性修复（500 问题）

- 修复项目阶段接口中 `attachments=None` 导致的 Pydantic 校验失败（500）。
- 兼容措施：
  - 接口返回前兜底把空附件归一为 `[]`。
  - SQLite 启动时自动补齐 `attachments` 列并修复历史空值数据。
