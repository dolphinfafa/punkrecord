# 2026-06-11 Milestone

## MCP 新增任务审核工具

### 背景

延续 2026-06-08 的 MCP 服务，应需求补充「团队任务审核」能力：让 AI 客户端通过 MCP 查看需要本人审核的任务，并执行通过/驳回。全部在 `dev` 分支。

### 改动

`backend/app/api/mcp_server.py` 新增 3 个工具（MCP 工具总数 19 → 22）：

- **`list_tasks_to_review`**：查看团队任务中待我审核的 `pending_review` 任务。工具内部先调 `/auth/me` 取本人 id，再以审核人过滤调 `/todo/team`（与待办角标"待我审核"口径一致，含"审核人未显式设置时由我创建"的隐含情形）。
- **`approve_todo(todo_id, comment?)`**：审核通过 → `done`，可附审批意见。转发 `POST /todo/{id}/approve`。
- **`reject_todo(todo_id, comment)`**：审核驳回 → 打回 `open`，需填驳回理由。转发 `POST /todo/{id}/reject`。

均复用现有 REST 与权限（仅审核人可操作、仅 `pending_review` 可审核），沿用「httpx 转发本机 REST」模式，零逻辑重复。前端 MCP 页「可用工具」列表取自 `/mcp-info`，自动显示新工具，无需改前端。

### 验证

构造一个"待 zheyang 审核"的 `pending_review` 任务，通过 MCP 端到端：
- `list_tasks_to_review` 正确列出待我审核任务 ✓
- `approve_todo` → 状态 `done`、记录审批意见 ✓
- `reject_todo` → 状态打回 `open`、记录驳回理由 ✓
- 测试数据已清理。

## 生产部署 v2.0.0（2026-06-11）

把 v1.0.8 之后的全部更新（Agent Token/Skill、06-05 系列修复、MCP 服务+审核工具）一次性部署到生产（`punkrecord.yios.cn`）。

### 关键环境事实
- **dev 后端实由 PM2 托管**（`punkrecord-backend`，conda env `punkrecord`，`uvicorn --reload`），不是 `dev.sh`（其 `punk` env 是旧脚本）。
- **生产由 PM2 托管**（`punkrecord-api`，原 venv = Python 3.9.5）；前端 nginx 静态托管 `/srv/punkrecord/frontend/dist`；DB `punkrecord_deploy`；`AUTO_CREATE_TABLES_ON_STARTUP=true`。
- 生产 main 与 origin **曾分叉**：分叉仅是 Python 3.9 兼容 hotfix（`document_parser.py` 的 `int|None`→`int=None`、`vector_store.py` 懒加载 chromadb 避免旧 sqlite 崩溃）。升级 3.11 后这些补丁基本不再需要；保留了 `vector_store.py` 懒加载版（更健壮）。
