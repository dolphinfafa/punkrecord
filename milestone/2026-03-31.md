# 2026-03-31 Milestone

## 多模块功能增强 + 版本更新日志 + 财务导出

### 1. 背景

本次迭代覆盖多个模块的功能增强和体验优化，主要包括：版本更新日志系统、财务交易编辑/导出、合同状态编辑、Bug 管理 Agent 文档增强、以及多处前端输入校验和显示优化。

### 2. 新增功能

#### 2.1 版本更新日志（Changelog）

- **后端**：新增 `ChangeLog` 模型（`backend/app/models/shared.py`），包含 version/title/content(Markdown)/published_by_user_id/published_at 字段
- **后端**：新增 `backend/app/api/changelog.py`，提供 CRUD API（GET/POST/PATCH/DELETE），L0 权限控制（manager_user_id 为空的顶级员工）
- **后端**：`main.py` 注册 changelog 路由
- **前端**：新增 `frontend/src/api/changelog.js` API 模块
- **前端**：`DashboardPage.jsx` 新增版本更新日志区域（最近活动下方），下拉选择版本，L0 可编辑/删除
- **数据库**：新增 `changelog` 表及迁移

#### 2.2 财务交易增强

- **后端**：`finance.py` 交易 PATCH 支持编辑全字段（之前仅部分字段），编辑后自动重算关联合同 pending_amount
- **后端**：`finance.py` Schema `TransactionUpdate` 扩展为支持全字段编辑
- **后端**：交易列表新增 `date_from`/`date_to` 日期筛选参数
- **后端**：新增 `GET /api/v1/finance/transactions/export-excel` 导出 Excel 接口（支持日期筛选）
- **前端**：`TransactionListPage.jsx` 新增日期筛选器 + 导出 Excel 按钮 + 编辑按钮
- **前端**：`CreateTransactionModal.jsx` 支持编辑模式（接收 initialData）

#### 2.3 合同管理增强

- **后端**：`contract.py` 支持编辑 status 字段 + 编辑 amount_total 时自动重算 pending_amount（考虑已付款金额）
- **后端**：`ContractUpdate` Schema 新增 status 字段
- **前端**：`CreateContractModal.jsx` 编辑模式下显示合同状态下拉框
