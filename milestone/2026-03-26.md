### 2. 端口统一

| 服务 | 旧端口 | 新端口 |
|------|--------|--------|
| 后端 API | 8085/8086 | 15085 |
| 前端 Web | 5173/5174 | 15173 |
| NestJS API | 3000 | 15030 |

不再区分 dev/main 分支端口，所有环境统一使用新端口。涉及 15 个文件修改。

### 9. 项目"我方主体"数据源修正

项目编辑/创建的"我方主体"下拉菜单应从 `counterparty`（交易方）表加载，而非 `our_entity`（组织主体）表。

- `ProjectEditModal` / `ProjectCreateModal` 改回使用 counterparties 数据
- 移除 `Project` 模型 `our_entity_id` 的 `our_entity` 外键约束（开发库+生产库均已 ALTER）
- 改用 `Promise.allSettled` 防止单个请求失败导致全部数据丢失
- `our_entity` 表仍保留：todo/财务/请假等模块作为"组织主体"使用

**两张表的区别**：
| 表 | 用途 |
|---|---|
| `our_entity` | 系统组织主体（公司），用于 todo/财务/请假等内部记录归属 |
| `counterparty` | 交易方（甲方/乙方），用于合同和项目中的商业关系 |

### 10. 生产环境部署

2. 生产服务器 `git pull origin main` + `pm2 restart punkrecord-api`

4. 数据库 ALTER：feature_list/deliverables → LONGTEXT，移除 our_entity_id 外键
