# 2026-03-07 Milestone

## 数据库从 SQLite 迁移到 MySQL

### 1. 迁移背景

项目原使用 SQLite 作为开发数据库，配置层已预留 MySQL 支持（`config.py` 中 `DB_TYPE` 切换、`pymysql` 驱动已在依赖中）。本次正式切换到远程 MySQL 8.0 实例。

### 2. MySQL 保留字处理

`user` 是 MySQL 保留字，直接使用会导致建表失败。

- 将 `User` 模型的 `__tablename__` 从 `"user"` 改为 `"users"`
- 更新 6 个模型文件中共 29 处 `foreign_key="user.id"` 引用为 `foreign_key="users.id"`
- 涉及文件：`iam.py`、`todo.py`、`project.py`、`contract.py`、`finance.py`、`shared.py`、`approval.py`

### 3. 移除 SQLite 专用代码

- 删除 `main.py` 中的 `_ensure_user_profile_columns()` 函数（该函数使用 SQLite 的 `ALTER TABLE ADD COLUMN` 语法在启动时补列，MySQL 全新建表不需要）

### 4. 配置变更

| 文件 | 变更 |
|------|------|
| `backend/.env` | `DB_TYPE=sqlite` -> `DB_TYPE=mysql`，`DB_PORT=3306` -> `DB_PORT=13306`，`AUTO_CREATE_TABLES_ON_STARTUP=true` |
| `backend/alembic.ini` | `sqlalchemy.url` 从 SQLite 路径改为 MySQL 连接串 |

### 5. 数据库初始化

- MySQL 实例：`14.103.133.34:13306`，数据库 `punkrecord_dev`（已预建）
- 通过 `SQLModel.metadata.create_all()` 成功创建 26 张表
- 运行 `create_admin.py` 创建管理员和种子数据（角色、权限、审批流）
- 登录验证通过（`admin / admin123`）

### 6. 文档更新

- `project-index.md`：数据库描述从"SQLite 开发 / MySQL 生产"改为"MySQL 8.0"
- `data-models.md`：新增 MySQL 驱动和 `users` 表名说明
- `workflows.md`：新增"数据库配置"章节，记录连接信息和注意事项
- `conventions.md`：新增"数据库命名注意"章节，记录 `users` 表名规则

### 风险等级: high
- 数据库引擎切换影响全部数据持久化
- `user` -> `users` 表名变更涉及 7 个模型文件 29 处外键引用
- 旧 SQLite 数据不自动迁移（全新建库）
- 远程 MySQL 依赖网络连通性
