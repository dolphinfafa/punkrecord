## 功能实现

### 项目与任务

- Bug 管理改为 `/project/:id/bugs` 页面，支持当前项目跨端标题子串搜索、原有筛选、分页、图片和编辑。
- 搜索条件以 URL 为准，支持刷新和浏览器返回/前进；忽略过期查询响应。
- 项目详情、开发进度、Bug 与待办共用 `TodoItem`；功能清单重复同步不再删除重建，保留 ID、状态、审核、图片和手工任务。
- 所有新任务入口及 MCP 截止日期必填，预计工时后续按用户要求调整为默认 0、非负数、最多两位小数（详见下方追加记录）。历史待验收缺少提交时间时必须撤回重提。
- 独立记录最终通过版本的提交时间；经理审核等待时间不用于计算延期。

### 独立请假

- 新增 `/leave`，保留工作台、小程序和原 REST 路径兼容。
- 请假不再创建或修改待办；通知按请假单关联。历史请假待办保留但隐藏，禁止旧状态操作，移除旧审批级联逻辑。
- 工作日历共用于请假天数与早会考勤；审批扣假期走统一流水，补批上午请假冲正早会扣款。
- 微信编号、引用及批量指令区分任务和 `leave:<uuid>`。MCP 新增独立请假待审批、批准、驳回工具。

### 贝利

- 新增 `/beli`，L0 管理非 L0 员工，普通员工只看自己；支持贝利/假期调整及账户流水。
- 用户管理移除贝利与假期调整、重置入口；旧余额写入接口拒绝绕过流水。
- 工资由 admin 角色通过员工管理专用入口维护；普通用户、贝利页面/API 和 MCP 不返回工资或内部计算快照。
- 正数工时任务完成后进入独立奖励队列，L0 审核通过才发放，自建任务同样适用；审核调整工时、日期、重要级同步原任务。
- 奖励按基本工资换算、工时、重要级和上海自然日延期系数计算；Decimal 两位小数结算。重开先冲销，再次验收与审核后重新发放。
- 余额、订单与奖励使用行锁、唯一事件键和结算快照。已发奖励锁定实际计划变更，但不阻止标题、备注及未变化计划值回传。

### 考勤与商城

- 启用日起，有早会记录的工作日按精确姓名、同日名单并集结算；非 L0 在职员工缺席扣 500，可为负数。
- 上午已批请假豁免；名单纠正、删除会议、日历调整与补批请假进行差额冲正。L0 可填写原因永久作废员工当日扣款。
- 首次结算保存姓名与应到身份，避免以后更名、停用、晋升改写历史考勤；后台每 5 分钟补结算。
- 商城支持商品图、上下架、假期/实物；申请冻结余额与库存，L0 通过后扣款、假期到账或进入待发货。
- 拒绝/取消释放冻结，未发货实物支持退款并恢复库存；发货记录必填，已发货不能普通退款。
- 修复非 HTTPS 开发地址缺少 `crypto.randomUUID` 的兼容问题，手机侧栏自动收起、表格内部滚动及任务表单窄屏布局。
