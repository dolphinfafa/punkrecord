# 2026-05-09 Milestone

## Agent Skill + Agent Token 系统 (v2.0.0)

### 1. 背景

将 PunkRecord 的能力打包为 Claude Code Skill，让 AI Agent 通过学习 Skill 文档 + 获取用户的 Agent Token 来代理用户操作系统。覆盖全部 9 个模块（待办、请假、项目、合同、财务、会议、知识库、组织管理、版本日志）。

### 2. Agent Token 系统（后端）

#### 2.1 数据模型

新增 `AgentToken` 模型（`shared.py`）：
- `user_id`：关联用户
- `token`：`pat_` + 64 位 hex（唯一索引）
- `name`：用户自定义名称
- `expires_at`：到期时间（可选，None=永久）
- `last_used_at`：最后使用时间

#### 2.2 认证中间件

`get_current_user()`（`auth.py`）增加 Agent Token 路径：
- 识别 `pat_` 前缀 → 查表验证 → 检查有效期 → 更新最后使用时间 → 映射到用户
- 与原有 JWT 路径并存，Token 代表用户身份，权限与该用户一致

#### 2.3 管理 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/auth/agent-tokens` | 生成（名称 + 有效期），Token 仅创建时返回明文 |
| GET | `/api/v1/auth/agent-tokens` | 列表（token 仅显示 preview） |
| DELETE | `/api/v1/auth/agent-tokens/{id}` | 删除（直接从数据库移除） |

### 3. 前端 Token 管理 UI

工作台左列版本日志下方新增"Agent 密钥"区域：
- 生成密钥弹窗（名称 + 有效期选择）
- 生成后显示 Token 明文 + 复制按钮（HTTP 环境 fallback execCommand）
- 密钥列表（名称、preview、创建时间、到期时间、最后使用时间）
- 删除按钮（确认后从数据库移除）
