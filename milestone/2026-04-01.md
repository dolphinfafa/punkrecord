# 2026-04-01 Milestone

## Bug 管理重构 + 后端 Todo API 扩展 + 本地数据库环境

### 1. 背景

本次迭代聚焦 Bug 管理模块的全面重构，包括编辑功能、配图增删改查、独立 Agent 状态字段、筛选功能等。同时扩展后端 Todo API 以支持 link 合并更新和 assignee 更新，并切换本地开发数据库。

### 2. Bug 管理重构

#### 2.1 Bug 列表编辑功能

- 每条 Bug 行增加"编辑"按钮，点击后表单变为编辑模式，预填所有字段
- 编辑模式下可修改 Bug 的所有属性（标题、描述、状态、优先级、执行人、测试人员等）

#### 2.2 Bug 配图增删改查

- 编辑时显示已有图片列表，支持单张删除和撤销删除
- 可继续添加新图片，新旧图片混合展示
- 保存时统一处理图片的增删操作

#### 2.3 独立 agent_status 字段

- AI 修复状态从 `todo.status` 解耦，改为存储在 `TodoItem.link.agent_status`
- 可选值：`ai_fixing`（AI 修复中）、`ai_fixed`（AI 修复完成）
- Bug 管理页面新增"Agent 状态"列，独立展示 AI 修复进度
- Agent 文档更新，明确说明 `status` 和 `agent_status` 互不影响

#### 2.4 Bug 管理 UI 增强

- 弹窗宽度从 1200px 增加到 1500px，容纳更多列信息
- 新增四维筛选功能：状态、Agent 状态、开发人员、测试人员

### 3. 后端改动

#### 3.1 TodoUpdate Schema 扩展

- 新增 `link`（dict）字段：支持 link JSON 的合并更新，不覆盖已有键
- 新增 `assignee_user_id`（int）字段：支持更新任务执行人

#### 3.2 update_todo API 增强

- PATCH `/api/v1/todo/{todo_id}` 支持 link 合并更新逻辑（dict() 拷贝 + 合并 + flag_modified）
- 支持通过 `assignee_user_id` 更新任务的 assignee

#### 3.3 AI 工作流状态转换

- AI workflow transitions 改为只更新 `link.agent_status`，不再修改 `todo.status`
- 修复 SQLAlchemy JSON 字段脏检测问题：使用 `dict()` 拷贝 + `flag_modified()` 标记

### 4. 数据库环境

- 新建本地数据库 `punkrecord_local`（127.0.0.1:3306，用户 punkrecord）
- 从远程 `punkrecord_dev` 导入数据到本地
- `.env` 切换为连接本地数据库，日常开发不再直连远程库
