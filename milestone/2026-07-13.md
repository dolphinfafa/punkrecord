# 2026-07-13 Milestone

## 图片上传体验优化

### 背景

用户反馈创建待办事项时上传图片只能看到文件名，没有缩略图预览；创建完成后详情页也看不到已上传图片。同时希望系统内所有上传图片的入口都能支持粘贴已经复制好的图片或截图。

### 前端实现

- 新增 `frontend/src/utils/clipboardImages.js`
  - 从剪贴板提取图片文件。
  - 为无文件名的粘贴图片生成 `pasted-image-YYYYMMDD-HHMMSS-N.ext` 文件名。
  - 提供图片文件筛选与多文件合并工具。
- 新增 `frontend/src/components/common/ImagePasteUpload.jsx` + `.css`
  - 支持点击选择、拖拽上传、Ctrl+V 粘贴图片。
  - 上传前生成 object URL 缩略图预览。
  - 支持单图/多图、紧凑模式、大小限制和移除。
- 已接入的图片入口：
  - `frontend/src/components/todo/TodoModal.jsx`
  - `frontend/src/components/todo/TodoDetailModal.jsx`
  - `frontend/src/pages/project/components/BugManagementModal.jsx`
  - `frontend/src/pages/auth/ProfileSetupPage.jsx`
  - `frontend/src/pages/iam/UserListPage.jsx`
  - `frontend/src/pages/contract/components/ContractAttachmentsModal.jsx`
  - `frontend/src/pages/project/components/ProjectAttachmentsModal.jsx`

### 后端修复

- `backend/app/api/todo.py`
  - `_enrich_todo()` 在返回任务前统一规范化 `link.todo_images`。
  - 复用 `_serialize_todo_images(todo)` 去除内部 `stored_name`，补齐 `download_path`。
  - 创建待办后，前端详情页可立即读取并展示已上传图片。

## 会议记录支持文稿导入

### 背景

用户反馈会议音频 ASR 仍存在漏听和说话人识别不准确的问题。为绕过单一 ASR 的准确率限制，会议记录需要支持上传已经识别好的文稿，而不是只能上传音频。

### 后端实现

- `backend/app/api/meeting.py`
  - 新增 `POST /api/v1/meeting/records/{meeting_id}/upload-transcript`。
  - 支持 Word `.docx` 与 PDF 文稿，单文件最大 20MB。
  - 复用 `app.services.document_parser.extract_text` 提取文本。
  - 支持以下说话人格式：
    - `讲话人1：内容`
    - `说话人2：内容`
    - `Speaker 1: 内容`
    - `张三：内容`
    - `[00:01-00:04] 张三：内容`
  - 导入成功后删除旧转写分段，写入新 `MeetingTranscriptSegment`，更新 `speaker_mapping` 和参会人，清空旧纪要，会议状态置为 `transcribed`。
  - 正在处理中的会议不能上传文稿，已归档会议不能替换文稿。
- 新增 `backend/tests/test_meeting_transcript_import.py`
  - 覆盖编号说话人、英文 Speaker、实名说话人、时间码、无说话人标签兜底。

### 前端实现

- `frontend/src/api/meeting.js`
  - 新增 `uploadTranscript(id, file)`。
- `frontend/src/pages/meeting/components/UploadAudioModal.jsx` + `.css`
  - 创建会议弹窗新增导入方式：空白、音频、文稿。
  - 文稿模式创建会议后自动上传 Word/PDF 并导入转写分段。
- `frontend/src/pages/meeting/MeetingDetailPage.jsx` + `.css`
  - 无音频会议可上传文稿。
  - 已有音频会议可上传文稿替换当前转写。
  - 无音频文稿分段显示静态“文稿”，不展示不可播放的时间按钮。
