# 2026-05-07 Milestone

## 待办编辑全字段 + 图片修复 + 工作台统计优化 (v1.0.8)

### 1. 背景

两个用户反馈的优化需求：
1. 待办事项编辑时应能修改所有字段（分配人、图片等），且只有相关人员可编辑
2. 工作台"已完成"统计应仅统计本周完成的任务

### 2. 待办编辑全字段支持

#### 2.1 编辑模式字段开放

- **分配人**：编辑模式下显示分配人下拉框（之前仅创建时可选）
- **图片**：编辑模式下可添加新图片，显示已有图片数量提示
- **所属项目**：编辑模式下只读展示项目名称（不可修改，避免影响关联关系）

#### 2.2 编辑时分配人列表为空修复

- 原因：用户列表和项目列表仅在 `mode === 'create'` 时加载
- 修复：改为 `isOpen` 时都加载，创建和编辑模式共用

#### 2.3 图片上传修复

- **创建时图片未传递**：`TodoModal` 的 `submitData` 缺少 `images` 字段，导致 `handleCreateTodo` 中 `formData.images` 为 undefined
- **编辑时无法添加图片**：`handleEditTodo` 未处理图片上传
- 修复：submitData 包含 images；handleEditTodo 增加图片上传逻辑

### 3. 编辑权限控制

前端 `canEditTodo` 和后端 `_can_access_todo` 统一增加 `reviewed_by_user_id` 检查。

可编辑角色：创建人、执行人（负责人）、审核员、执行人的直属上级。其他人只能查看不能编辑。

### 4. 工作台"已完成"统计本周

- 原逻辑：统计所有 status=done 的任务总数
- 新逻辑：仅统计 `done_at >= 本周一 00:00` 的任务，与"本周完成"文案一致
