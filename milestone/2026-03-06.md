## AI Agent Bug 修复工作流 + 项目文档体系

### 1. AI Agent Bug 修复工作流

#### 后端变更
- `TodoStatus` 枚举新增 `AI_FIXING`（AI 修复中）和 `AI_FIXED`（AI 已修复）两个状态
- `POST /api/v1/todo/{todo_id}/status` 新增 AI 状态转换逻辑:
  - `open/in_progress/blocked` -> `ai_fixing`（Agent 开始修复）
  - `ai_fixing` -> `ai_fixed`（Agent 完成修复）
  - `ai_fixed` -> `open/pending_review/done`（人工接管验收）

#### 前端变更
- Bug 管理弹窗新增 "Agent 文档" 面板按钮
- 点击展开自动生成的 Agent 工作手册，内容包含:
  - 项目信息（名称、ID、当前操作人）
  - 项目成员列表（含 user_id 和角色）
  - 认证方式（Bearer Token 获取方法）
  - 4 个 API 接口说明（获取 Bug 列表、开始修复、完成修复、获取详情）
  - 完整工作流程和状态流转图
- 支持一键复制整个文档
- Bug 列表新增 `AI 修复中`（紫色）和 `AI 已修复`（绿色）状态徽标

#### 工作流程
```
工作人员打开 Bug 管理
  -> 点击 "Agent 文档"
  -> 一键复制
  -> 粘贴给 AI Agent
  -> Agent 通过 API 拉取 Bug 列表
  -> 筛选负责人的 Bug
  -> 标记为 "AI 修复中"
  -> 修复代码
  -> 标记为 "AI 已修复"
  -> 测试人员人工验收
```

## 员工档案管理 + 首次登录流程

### 5. 员工档案字段扩展

#### 后端变更
- `User` 模型新增 9 个字段：`birthday`、`id_number`、`home_address`、`graduation_school`、`education_level`、`id_card_image`、`resume_file`、`profile_completed`、`must_change_password`
- 新增 `EducationLevel` 枚举（high_school / associate / bachelor / master / doctorate / other）
- `main.py` 启动时通过 `ALTER TABLE ADD COLUMN` 为已有数据库表添加新列，现有用户默认 `profile_completed=1`、`must_change_password=0` 避免锁定
- `create_admin.py` 管理员用户显式设置 `profile_completed=True`、`must_change_password=False`

#### 新增 API 端点
- `POST /auth/complete-profile` — 首次登录完善档案 + 设置新密码
- `POST /auth/change-password` — 修改密码（需验证原密码）
- `POST /iam/users/{user_id}/reset-password` — 管理员重置密码（默认 `punkrecord123`）
- `POST /iam/users/{user_id}/id-card-image` — 上传身份证图片
- `POST /iam/users/{user_id}/resume` — 上传简历 PDF
- `GET /iam/users/{user_id}/files/{filename}` — 下载用户文件

#### Schema 变更
- `TokenResponse` 新增 `profile_completed`、`must_change_password`
- `UserUpdate` / `UserResponse` 新增档案相关字段
- 新增 `ProfileCompleteRequest`、`ChangePasswordRequest`

### 6. 首次登录流程（前端）
- 新增 `ProfileSetupPage.jsx`（`/profile-setup` 路由）
- 表单字段：邮箱、手机号、生日、学历、身份证号、家庭住址、毕业学校、身份证图片上传、简历 PDF 上传、新密码 + 确认密码
- `App.jsx` 的 `ProtectedRoute` 在 `!profile_completed || must_change_password` 时重定向到 `/profile-setup`
- `AuthContext` 登录返回值和 `/auth/me` 解析包含档案状态

### 7. 管理后台员工编辑增强
- 编辑弹窗新增「个人档案」区域（生日、学历、身份证号、家庭住址、毕业学校）
- 身份证显示为图片预览，简历显示为可点击的 PDF 链接，均支持重新上传
- 用户列表新增「重置密码」按钮（仅 L0 管理员可见）

### 8. Bug 修复
- **编辑弹窗白屏**：`Upload` 组件在 JSX 中使用但未 import（import 中写的是 `Image`），点击编辑时 isEdit=true 渲染文件上传区域触发 ReferenceError
- **日期选择器不可点击**：CSS `.login-form .form-group input` 全局设置了 `padding-left: 48px !important`，覆盖了 date input 的日历图标区域。改为仅对 `.input-with-icon input` 设置左内边距
- **档案页面内容溢出**：`.login-container` 使用 `height: 100vh` 导致内容超出视口时被截断。改为 `min-height: 100vh` + `padding` + `overflow-y: auto`
- **文件预览 401 错误**：`<img src>` / `<a href>` 直接请求不携带 Bearer Token，cookie 因 `secure=true` 在 HTTP 开发环境下不发送。改为通过 axios 下载文件生成 blob URL 显示
