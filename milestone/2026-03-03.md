# 2026-03-03 项目进度记录

## 今日完成

1. 小程序 Todo 模块补齐“我的/团队”双视图
- `pages/todo/index.*` 新增“我的待办 / 团队待办”切换。
- 团队待办支持按状态筛选、关键词搜索，并展示负责人信息。
- 对待审核任务补齐团队侧“通过/驳回”动作入口（按权限显示）。

2. 小程序请假申请与审批流程接入
- 在 `pages/todo/index.*` 内新增请假申请区块：
  - 请假类型选择、起止日期、原因输入、提交。
  - 我的请假记录展示（类型/状态/时间范围）。
  - 待我审批列表展示（通过/驳回）。
- `services/todo.js` 新增请假相关接口封装：
  - `createLeave` / `listMyLeaves` / `listTeamPendingLeaves` / `approveLeave` / `rejectLeave`。

3. 底部导航改为自定义 TabBar（样式与可读性优化）
- 新增 `miniprogram/custom-tab-bar/` 组件（`index.js/json/wxml/wxss`）。
- `app.json` 切换 `tabBar.custom = true`。
- 底部菜单文本字号提升并增加图标字符，改善可读性。
- `app.wxss` 增加容器底部安全区 padding，避免页面内容被导航遮挡。

4. 财务账户“未命名账户”问题修复
- 排查结论：前端字段映射问题，不是 API 调用失败。
- `pages/finance/index.js` 将账户名称优先字段从 `name` 修正为 `account_name`。
- 账户列表补充副信息显示（银行名或账户类别），并微调列表样式。

5. 登录后“我的”页显示访客问题修复
- 根因：登录后先请求 `/auth/me` 再写 token，导致用户信息获取失败并落库为 `null`。
- 修复：`pages/login/index.js` 先写 token，再请求 `/auth/me`。
- 兜底：`pages/mine/index.js` 在本地 user 为空但 token 存在时自动回拉 `/auth/me` 并缓存。
