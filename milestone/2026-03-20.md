# 2026-03-20 Milestone

## 全系统 31 项 QA 修复

### 1. 背景

QA 团队对系统全模块进行测试，发现 31 项问题，涵盖 UI 显示、后端逻辑、500 错误、功能缺失等。本次集中修复。

### 2. 修复内容

#### UI/CSS 修复 (#7, #9, #11, #12, #25, #30)

- **根因**：全局 CSS 变量使用 Catppuccin Macchiato 暗色主题（`--bg-crust: #181926`），导致所有 Modal 中的 input/select 背景为黑色
- **修复**：`index.css` 全局变量改为亮色主题；`Modal.css` 中所有颜色从暗色改为白底深字
- 涉及模块：部门管理图标、交易方输入框、合同编辑/创建、财务账户、所有模态框

#### 仪表盘 (#1, #2)

1. **待审批统计**：从个人任务 `pending_review` 改为调用团队任务 API 获取 `pending_review` 数量
2. **快速新建任务**：`our_entity_id` 改为可选并自动解析；TodoModal 只发送后端期望的字段

#### 待办事项逻辑 (#3, #4, #5)

3. **团队任务过滤**：从按 `manager_user_id` 查直属下属，改为按 `creator_user_id` 过滤（审核人视角，与级别无关）
4. **请假审批可见性**：遍历 manager 链查找所有下属的请假申请，不限于直属
5. **请假创建审批任务**：提交请假后自动为审批人创建 TodoItem（source_type='approval_step'，status='pending_review'）

#### 用户管理 (#6)

6. **停用用户登录**：后端已有 `user.status != ACTIVE` 检查，确认正常

#### 登录页 (#28, #29)

28. **密码显示切换**：新增 Eye/EyeOff 按钮切换 password/text 类型
29. **登录错误提示**：根据后端返回消息显示具体原因（停用、密码错误等）

#### 合同管理 (#10, #13)

10. **交易方编辑**：前后端完整实现（后端新增 PATCH 端点，前端复用 CreateCounterpartyModal 支持 initialData）
13. **保存按钮文本**：`{loading ? '保存' : '保存中...'}` 修正为 `{loading ? '保存中...' : '保存'}`

#### 项目管理 (#8, #14-24)

8. **成员添加搜索/筛选**：新增姓名搜索框和职位筛选下拉
14. **创建项目 500**：`Project.our_entity_id` 改为可选（nullable），无 OurEntity 时不报错
15. **项目任务创建**：TodoModal 参数匹配修复
16. **阶段列顺序**：操作列和备注列位置互换
17. **功能清单 Excel 样式**：新增后端 openpyxl 端点生成带深蓝色表头、边框、斑马纹的 Excel
18. **报价单导出 500**：前端改用 fetch 正确处理 blob 响应
19. **B2C 原型确认**：隐藏原型确认单按钮（仅 B2B 显示）
20. **原型确认 500**：Python 3.9 类型兼容修复（`list[dict]` → `List[Dict]`）
21. **同步功能清单 500**：`progress_percentage` → `progress` 字段名修复，值范围改为 0.0-1.0
22. **Bug 创建失败**：移除前端过度校验
23. **审核员不一致**：Bug 的 reviewer 改用 `currentUserId`
24. **Bug 状态不变**：放宽权限，允许 `creator_user_id` 也可操作 start/submit

#### 财务管理 (#26, #27)

26. **账户数据缺失**：`FinanceAccountResponse` 补充 `bank_branch` 和 `account_no_masked` 字段
27. **交易明细 500**：`our_entity_id` 改为可选并自动解析有效 OurEntity

#### 配置 (#31)

31. **LiteLLM API_KEY**：更新为新值 `sk-TzLTEohDg_5CxoRaqBOJpQ`
