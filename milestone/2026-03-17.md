# 2026-03-17 Milestone

## 修复会议记录模块 3 个 Bug + ASR 服务重写

### 1. 背景

2026-03-16 完成企业大脑和会议记录两大功能模块的开发后，用户测试发现会议记录模块存在 3 个 Bug：上传音频后状态显示失败、上传弹窗标题输入框背景黑色看不清、上传音频后无后续操作界面。

### 2. Bug 修复

#### Bug 1：上传音频弹窗标题输入框背景黑色

**问题**：`UploadAudioModal.css` 的 `.form-input` 没有显式设置 `background-color`，被全局深色样式覆盖导致输入框背景为黑色，文字不可见。

**修复**：添加 `background-color: #fff; color: #1a1a2e;`。

#### Bug 2：上传音频后无后续操作界面（前端字段名不匹配）

**问题**：`MeetingDetailPage.jsx` 中多处前端字段名与后端 API 返回的字段名不一致，导致转录文本、说话人映射等数据无法正确加载和展示。

**修复内容（7 处）**：

| 位置 | 错误 | 修正 |
|------|------|------|
| `loadTranscript` | 期望 `data.segments` 对象 | 后端返回扁平数组，改为 `Array.isArray(data) ? data : []` |
| `loadMeeting` | `data.archive_doc_id` | 改为 `data.archived_document_id` |
| `loadMeeting` | speaker_mapping 未从会议对象获取 | 添加 `setSpeakerMapping(data.speaker_mapping)` |
| `handleSaveTranscript` | 发送 `{...seg, text}` 全量字段 | 改为只发 `{id, content}` 匹配后端 `TranscriptBatchUpdate` schema |
| segment textarea | `segment.text` | 改为 `segment.content` |
| SSE 纪要解析 | `parsed.content` | 改为 `parsed.text`（后端发送 `{text: ...}`） |
| 时长显示 | `meeting.duration` | 改为 `meeting.duration_seconds` |

同步修复了 `MeetingListPage.jsx` 中的 `meeting.duration` → `meeting.duration_seconds`。

#### Bug 3：ASR 转录失败

经历了 3 轮排查和修复：

| 轮次 | 错误 | 原因 | 修复 |
|------|------|------|------|
| 第 1 轮 | `.env` 缺少配置 | `.env` 中未添加 `VOLC_ASR_APP_KEY` 和 `VOLC_ASR_ACCESS_KEY` | 补全 `.env` 中所有 ASR/ChromaDB/KB 配置项 |
| 第 2 轮 | `405 Method Not Allowed` | 原代码调用 `sauc/bigmodel` 端点（WebSocket 流式接口），只支持 GET 不支持 POST | 重写 ASR 服务，改用录音文件识别 HTTP API（submit + query 模式） |
| 第 3 轮 | `504 Gateway Timeout` | 本地存储无公网 URL，将 base64 data URI 作为音频 URL 导致超时 | 新增无认证音频下载端点 + `PUBLIC_BASE_URL` 配置，让豆包通过公网 URL 下载音频 |
| 第 4 轮 | `401 grant not found` | app_key 未开通大模型版 ASR 权限（`volc.bigasr.auc`） | 从大模型版 API 切换到标准版 API（`/api/v1/auc/submit` + `/api/v1/auc/query`） |

### 3. ASR 服务架构（最终方案）

```
用户上传音频
  → 保存到 meeting-audio/{uuid}.mp3
  → 后台异步调用 ASR：
    1. 构造公网 URL: https://dev-cn-01.yios.cn/punkrecord/api/v1/meeting/asr-audio/{stored_name}
    2. POST 提交到 openspeech.bytedance.com/api/v1/auc/submit
    3. 获取 task_id，每 2 秒轮询 /api/v1/auc/query
    4. 解析 utterances（含说话人分离），写入 meeting_transcript_segment 表
    5. 会议状态更新为 transcribed
```

**认证方式**：`app.appid` + `app.token` + `app.cluster=volcengine_auc`
**说话人分离**：`additions.with_speaker_info: true`
**音频访问**：新增 `/meeting/asr-audio/{stored_name}` 无认证端点（stored_name 为 UUID，不可猜测）
