# 2026-03-23 Milestone

## 待办事项/项目管理多项修复与优化

### 1. 背景

QA 团队继续测试后反馈了请假待办、项目创建、报价单保存、看板视图等多项问题，本次集中修复。

### 2. 修复内容

#### 请假待办事项角色修复

- **问题**：请假创建的待办任务 assignee 和 creator 分配不对
- **修复**：creator 和 assignee 都设为申请人 A，`reviewed_by_user_id` 设为 A 的上级
- 标题格式：`{姓名} - 请假申请`
- 描述包含：请假类型、时间范围、原因
- 截止时间：当天 23:59:59

#### 请假审批同步待办状态

- **问题**：请假申请审批/驳回后，待办清单中对应任务状态不更新
- **修复**：approve/reject 时通过 `source_id` 找到对应 TodoItem，批准设为 `done`，驳回设为 `dismissed`

#### 项目编号自动生成

- **问题**：创建项目时编号为空，只有 placeholder 提示
- **修复**：前端 `ProjectCreateModal` 初始化时自动生成 `PR-YYYYMMDD-NNN` 格式编号；后端 `project_no` 改为 Optional

#### 项目创建 500 错误（外键约束）

- **问题**：`our_entity_id` 传了不存在的 UUID，触发 FK 约束 `project_ibfk_1`
- **修复**：后端验证 entity 存在性，不存在则 fallback 或设 None；DB 已 ALTER TABLE 改为 nullable 并加 ON DELETE SET NULL

#### 报价单/功能清单保存 500（Data too long）

- **问题**：`project_stage.feature_list` 为 `varchar(255)`，JSON 数据超长
- **修复**：DB 改为 `LONGTEXT`，模型层改用 `sa_column=Column(TEXT)`

#### 报价单保存后不刷新

- **问题**：保存后页面显示旧数据，需退出重进
- **修复**：`onSave` 回调接收保存数据，`await loadData()` 后立即更新 `quoteStage` state

#### 团队任务显示自指派任务

- **问题**：creator == assignee 且无审核员的任务出现在团队列表
- **修复**：查询条件改为 `(creator==me AND assignee!=me) OR (reviewed_by==me)`

#### 看板已完成列折叠懒加载

- 看板初始只请求 open/in_progress/pending_review/blocked 四种状态
- done 列默认折叠显示"点击展开"
- 用户点击展开后才发请求加载已完成任务

#### 文本选择触发导航

- KB 文档列表、仪表盘活动项、会议列表的可点击行增加 `window.getSelection()` 检查

#### 登录失败闪跳

- 401 拦截器检测到已在登录页则不跳转，避免刷新循环

#### 待办列表分页

- 列表视图每页 20 条，底部翻页控件

### 3. 数据库变更

```sql
-- project.our_entity_id 改为 nullable
ALTER TABLE project DROP FOREIGN KEY project_ibfk_1;
ALTER TABLE project MODIFY COLUMN our_entity_id CHAR(36) NULL;
ALTER TABLE project ADD CONSTRAINT project_ibfk_1 FOREIGN KEY (our_entity_id) REFERENCES our_entity(id) ON DELETE SET NULL;

-- feature_list 扩容
ALTER TABLE project_stage MODIFY COLUMN feature_list LONGTEXT NULL;
```
