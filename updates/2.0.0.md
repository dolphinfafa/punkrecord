# v2.0.0 更新日志

**发布日期**：2026-05-09

---

## 新功能

- **Agent Token 系统**：用户可在工作台生成专用密钥（Agent Token），供 AI Agent 代理操作系统。支持设置有效期（30天/90天/180天/永久），一键复制，随时删除
- **PunkRecord Skill**：将平台全部能力（待办、请假、项目、合同、财务、会议、知识库等 9 大模块）打包为 Agent Skill，AI Agent 学习后即可通过 Token 代理用户操作
- **待办编辑全字段**：编辑任务时可修改分配人和添加新图片，所属项目只读展示
- **编辑权限控制**：仅创建人、执行人、审核员和直属上级可编辑任务

## 优化

- 工作台"已完成"统计改为仅统计本周（周一至今）完成的任务
- 编辑任务时显示已有图片数量提示

## 修复

- 修复创建任务时选择的图片未被上传的问题
- 修复编辑任务时分配人下拉列表为空的问题
- 修复 HTTP 环境下密钥复制按钮无反应的问题（增加 execCommand fallback）
