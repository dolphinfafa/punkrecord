# v2.0.0 更新日志

**发布日期**：2026-05-09 ｜ **最近更新**：2026-06-08

---

## 新功能

- **Agent Token 系统**：用户可在工作台生成专用密钥（Agent Token），供 AI Agent 代理操作系统。支持设置有效期（30天/90天/180天/永久），一键复制，随时删除
- **PunkRecord Skill**：将平台全部能力（待办、请假、项目、合同、财务、会议、知识库等 9 大模块）打包为 Agent Skill，AI Agent 学习后即可通过 Token 代理用户操作
- **待办编辑全字段**：编辑任务时可修改分配人和添加新图片，所属项目只读展示
- **编辑权限控制**：仅创建人、执行人、审核员和直属上级可编辑任务
- **待办角标提醒**（2026-06-05）：左侧"待办事项"导航与待办页"我的任务/团队任务"标签新增角标——蓝色为我的未开始+进行中任务数，红色为团队中待我审核的任务数
- **AI 创建项目任务**（2026-06-05）：创建任务时可直接指定所属项目（项目名或 ID）与任务类型（前端/后端/UI/产品），一步生成项目任务，无需多轮确认
- **任务图片查看**（2026-06-05）：新增按任务列出/下载相关图片的能力，支持按任务名查找
- **MCP 集成**（2026-06-08）：左侧导航新增「MCP」页面——PunkRecord 现已是一个 MCP 服务，可用密钥把平台接入 Claude Desktop/Code、Cursor、Cherry Studio 等 AI 客户端，让 AI 直接代你查看/创建待办、管理项目、提交请假、检索知识库等。页面提供密钥管理、端点地址、各客户端配置片段与工具说明（API 密钥管理从工作台迁至此页）

## 优化

- 工作台"已完成"统计改为仅统计本周（周一至今）完成的任务
- 编辑任务时显示已有图片数量提示
- **会议纪要提示词**（2026-06-05）：选择提示词预设时改为追加到自定义提示词框，保留已输入内容，不再清空
- **合同编号自动生成**（2026-06-05）：创建合同可不填编号，系统自动生成（`CNT-时间戳`），与页面规则一致
- **项目阶段顺序校验**（2026-06-05）：更新阶段状态须按顺序推进，前序阶段未完成（或未显式跳过）时不可直接更新后续阶段
- **知识库检索容错**（2026-06-05）：语义检索/AI 对话在服务未就绪时给出友好提示，不再报错

## 修复

- 修复创建任务时选择的图片未被上传的问题
- 修复编辑任务时分配人下拉列表为空的问题
- 修复 HTTP 环境下密钥复制按钮无反应的问题（增加 execCommand fallback）
- **阻塞/忽略任务**（2026-06-05）：修复通过 Agent 调用时原因参数位置不一致、需多次重试的问题（改为请求体接收）
