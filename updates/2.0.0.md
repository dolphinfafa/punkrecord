# v2.0.0 更新日志

**发布日期**：2026-05-09 ｜ **最近更新**：2026-06-11

> 本版本汇总 v1.0.8 之后的全部更新。核心主题：让 AI 能安全、便捷地代理你操作 PunkRecord —— 从 Agent Token / Skill，到完整的 MCP 服务。

---

## 重磅新功能

- **MCP 服务**（2026-06-08）：PunkRecord 现已是一个标准的 **MCP（Model Context Protocol）服务**。左侧导航新增「MCP」页面，提供 API 密钥管理、服务端点地址、各 AI 客户端（Claude Desktop/Code、Cursor、Cherry Studio 等）配置片段与工具说明。配置好密钥后，AI 客户端即可直接调用平台工具——查看/创建待办、管理项目、提交请假、检索知识库等。
  - **任务审核工具**（2026-06-11）：MCP 新增「查看需要我审核的任务」并支持**通过 / 驳回**，管理者可让 AI 协助处理下属上报的待审任务。
  - 目前 MCP 共开放 22 个工具（含读 / 写 / 审核三类）。
- **Agent Token 系统**（2026-05-09）：可生成专用密钥（`pat_`）供 AI 代理操作，支持有效期（30/90/180 天/永久）、一键复制、随时删除。密钥管理已统一收敛到「MCP」页面。
- **PunkRecord Skill**（2026-05-09）：将平台九大模块能力打包为 Agent Skill，供 AI 学习后通过密钥代理操作。

## 待办与项目

- **AI 创建项目任务**（2026-06-05）：创建任务时可直接指定所属项目（项目名或 ID）与任务类型（前端/后端/UI/产品），一步生成项目任务，无需多轮确认。
- **任务图片查看**（2026-06-05）：新增按任务列出 / 下载相关图片的能力，支持按任务名查找。
- **待办角标提醒**（2026-06-05）：左侧「待办事项」导航与待办页「我的任务 / 团队任务」标签新增角标——蓝色为我的未开始 + 进行中任务数，红色为团队中待我审核的任务数。
- **项目阶段顺序校验**（2026-06-05）：更新阶段状态须按顺序推进，前序阶段未完成（或未显式跳过）时不可直接更新后续阶段。

## 合同与知识库

- **合同编号自动生成**（2026-06-05）：创建合同可不填编号，系统自动生成（`CNT-时间戳`），与页面规则一致。
- **知识库检索容错**（2026-06-05）：语义检索 / AI 对话在服务未就绪时给出友好提示，不再报错。

## 会议纪要

- **提示词预设优化**（2026-06-05）：选择提示词预设时改为追加到自定义提示词框，保留已输入内容，不再清空；切换预设自动剥离上次追加段。

## 修复

- **阻塞 / 忽略任务**（2026-06-05）：修复通过 AI 调用时原因参数位置不一致、需多次重试的问题（改为请求体接收）。
- 修复 HTTP 环境下密钥复制按钮无反应的问题（增加 execCommand fallback）。

---

> 说明：v2.0.0 起后端 MCP 服务依赖 Python 3.10+。
