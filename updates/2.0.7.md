# v2.0.7 更新日志

**发布日期**：2026-08-17

> 小版本：会议记录转写稿编辑能力增强，支持新增讲话人、插入/删除转写行，并修复保存修改 422 的问题。参会人员改为自动跟随转写稿中的说话人。

---

## 会议记录

- **转写稿完整编辑**：会议详情页的转写文本支持直接修改、新增讲话人、切换说话人、添加行、在任意行上方/下方插入行、删除行。
- **完整列表保存**：保存转写稿时前端提交 `replace=true` 的完整分段列表，后端按顺序重建 `segment_index`，并返回最新分段 ID，避免新插入行保存后缺少真实 ID。
- **422 修复**：后端允许新插入行携带临时 ID 或空 ID；只有有效 UUID 且属于当前会议时才更新原分段，否则创建新分段，避免保存修改时报 422。
- **参会人员自动同步**：参会人员不再单独手动编辑；上传文稿、保存转写稿、保存说话人映射后，系统会按转写分段中实际使用的 speaker 自动生成参会人员列表。
- **说话人映射同步**：修改 speaker 显示名后，顶部参会人员展示会同步刷新。
- **错误提示优化**：前端保存失败时会展示后端校验详情，便于定位具体字段问题。

## 开发与部署

- **版本号更新**：后端 `APP_VERSION` 更新为 `2.0.7`，`backend/.env.example` 同步更新。
- **数据库**：本版本无新增数据库字段，不需要执行 Alembic 迁移。
- **部署影响**：涉及后端 API 与前端会议详情页，部署时需要重启后端并重新构建前端。
