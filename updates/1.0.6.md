# v1.0.6 更新日志

**发布日期**：2026-04-22

---

## 新功能

- **会议记录无音频创建**：可直接通过标题、类型、日期创建会议记录，无需上传音频文件
- **详情页上传音频**：无音频的会议可在详情页补传音频文件，自动触发 ASR 转录
- **手动填写参会人员**：无音频会议支持在详情页手动输入参会人员名单
- **纯文字会议纪要**：无音频无转录时，可在"自定义提示词"中填写会议文字记录，AI 直接生成结构化会议纪要
- **ASR 大文件切片**：音频文件 > 300MB 时自动切片提交 ASR，说话人 ID 按切片编号区分，手动改名合并后 AI 纪要自动识别同一人

## 优化

- 创建会议弹窗精简为标题/类型/日期，创建后自动跳转到详情页
- "上传音频"按钮改为"创建会议"，流程更清晰

## 修复

- 修复大音频文件（> 300MB）base64 编码后超出 ASR API 限制导致转录失败但状态显示已转录的问题
- 修复 ASR 返回空结果时状态错误标记为已转录（现在正确标记为失败）
- 修复 httpx.ReadError 异常的 str() 为空字符串绕过错误检查的问题
