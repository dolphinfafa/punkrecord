# v2.0.3 更新日志

**发布日期**：2026-07-01

> 小版本：修复会议音频转录不完整和时间轴错位问题；财务交易支持删除已作废明细并修复 Excel 导出；MCP 同步财务作废/恢复/删除能力。

---

## 会议记录

- **长音频转录更完整**：大文件或长音频会统一转为 16k 单声道 mp3 后切片，切片间保留 5 秒重叠，并在合并时去重，减少切片边界漏字。
- **时间轴更准确**：切片改用精确 seek，转录段会加回原音频偏移并按开始时间重排，降低文字和播放器音频对不上的概率。
- **音频时长回写**：ASR 返回真实时长后写入会议记录，列表和详情可显示更准确的音频时长。
- **首段播放定位修复**：转录片段播放保留 `0` 秒合法时间点，避免点击首段跳到错误位置。

## 财务管理

- **删除已作废交易**：交易明细中，已作废行在“恢复”旁新增“删除”操作；正常交易必须先作废再删除，避免误删有效流水。
- **Excel 导出修复**：交易导出改为直接处理后端返回的 Blob，并修复中文文件名响应头编码问题，避免“无法识别的导出错误”。
- **导出跟随状态筛选**：导出 Excel 会带上当前状态筛选，作废交易导出时状态列显示“作废”。

## MCP 服务

- **交易查询增强**：`list_transactions` 增加 `account_id`、`txn_direction`、`status`、`page` 参数，可通过 `status=voided` 查询作废交易。
- **财务作废工具**：新增 `void_transaction` 与 `unvoid_transaction`，AI 客户端可作废或恢复财务交易。
- **删除作废交易工具**：新增 `delete_voided_transaction`，仅允许删除已作废交易。
- **工具数更新**：MCP 工具总数从 25 增至 28。

---

> 升级须知：本版本无新增数据库字段。部署后需确保后端运行在 `punkrecord` Python 环境，并重启后端服务，使新增 MCP 工具和财务删除接口生效。
