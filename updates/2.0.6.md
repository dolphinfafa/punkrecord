# v2.0.6 更新日志

**发布日期**：2026-07-22

> 小版本：MCP 服务补齐待办图片和 Bug 配图的可访问 URL，并新增 base64 图片读取工具，让 AI 客户端可以真正拿到图片内容。

---

## MCP 服务

- **待办图片 URL**：`get_todo`、`list_my_todos`、`list_todo_images` 会在 `link.todo_images` 或图片列表中补充 `api_download_url` / `download_url`。
- **Bug 配图 URL**：`get_todo`、`list_project_todos`、`list_tasks_to_review` 和任务状态变更类工具会在 `link.bug_images` / `link.bug_image` 中补充项目附件下载 URL。
- **认证边界**：图片 URL 不包含 token；下载时需要使用调用 MCP 时同一个 `Authorization: Bearer pat_xxx`。
- **直接传图工具**：新增 `get_todo_image(todo_id, image_id)` 与 `get_bug_image(project_id, attachment_id)`，返回 `file_name`、`content_type`、`size`、`content_base64`，适合无法额外发 HTTP 请求下载图片的 MCP 客户端。
- **公网 URL 推导**：优先从 `MCP_PUBLIC_URL` 推导 API base；未配置时根据请求的 `X-Forwarded-Proto` / `X-Forwarded-Host` / 子路径前缀推导，兼容生产根域名和开发 `/punkrecord/` 子路径。
- **工具数更新**：MCP 工具总数更新为 38 个。

## 开发与部署

- **版本号更新**：后端 `APP_VERSION` 更新为 `2.0.6`，`backend/.env.example` 同步更新。
- **数据库**：本版本无新增数据库字段，不需要执行 Alembic 迁移。
- **部署影响**：仅后端 MCP 服务与文档变更，部署时重启后端即可；前端无需重新构建。

---

> 升级须知：MCP 客户端继续使用原 Agent Token。图片 URL 需要调用方自行携带 Authorization 头；若客户端不方便下载 URL，优先调用新增 base64 图片读取工具。
