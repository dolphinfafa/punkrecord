# v1.0.3 更新日志

**发布日期**：2026-04-02

## 优化

- **Bug 管理 — 开发人员选择**：新建 Bug 时开发人员下拉显示项目组所有成员，不再限制为前端/后端角色
- **Bug 管理 — 待办描述补全**：创建 Bug 后同步的待办事项描述自动包含实际结果、期望结果、复现步骤、备注
- **Bug 管理 — 筛选优化**：开发人员和测试人员筛选列表从实际 Bug 数据中提取，确保列表完整准确
- **版本更新日志**：编辑和展示支持 Markdown 格式（标题、列表、加粗、代码块等）

## 修复

- **开发环境登录失败**：修复 Vite 代理配置缺少 `/api` 路径匹配导致前端请求无法到达后端的问题
