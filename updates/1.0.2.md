# v1.0.2 更新日志

**发布日期**：2026-04-01

---

## 新功能

- **Bug 编辑功能**：Bug 列表新增"编辑"按钮，支持修改已创建的 Bug 所有字段
- **Bug 配图管理**：编辑 Bug 时可查看已有配图、删除单张图片、继续添加新图片
- **Bug 筛选功能**：支持按状态、Agent 状态、开发人员、测试人员四维筛选，快速定位目标 Bug
- **Agent 状态追踪**：Bug 管理页面新增"Agent 状态"列，独立展示 AI 修复进度（修复中/已修复）

## 优化

- Bug 管理弹窗宽度增加至 1500px，信息展示更充分
- AI 修复状态与任务状态解耦，互不干扰，操作更清晰
- 后端任务更新接口支持更多字段（执行人变更、扩展属性合并更新）

## 修复

- 修复 AI 修复 Bug 时意外改变任务状态的问题
- 修复数据库 JSON 字段更新时脏检测失效的问题
