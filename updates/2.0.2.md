# v2.0.2 更新日志

**发布日期**：2026-06-22（2026-06-24 增补）

> 小版本：财务交易明细新增「作废」与「状态筛选」；MCP 交易批量写入与工具文档页；待办描述扩容与备注字段。

---

## 新功能

- **交易作废**：财务 → 交易明细，每条交易新增「作废」操作。作废后该交易**仍然显示但整行划线、状态标记为"作废"**，且**不再计入账户余额**；若交易关联了合同，会自动回退对应的待收/待付金额。作废可「恢复」。
- **按状态筛选交易**：交易明细工具栏新增「状态」筛选——全部 / 未完成 / 已完成 / 已对账 / 作废，配合日期筛选快速定位交易。

### 2026-06-24 增补

- **MCP 批量写入交易明细**：MCP 服务新增 `create_transactions`（一次批量写入多条交易，单条失败不影响其他）与 `list_accounts`（查询账户、获取 account_id）工具。AI 客户端可代为批量录入财务交易。
- **MCP 工具文档页**：MCP 集成页的工具列表每一项均可点击，进入该工具的**独立详细文档页**（完整参数说明与用法示例）。
- **待办描述扩容**：待办事项「描述」字段上限由 255 字符提升至 **1 万字符**，支持长文本。
- **待办新增「备注」**：待办新增/编辑弹窗与详情新增独立的「备注」字段（上限 2000 字符）。
